# Документация СМИБ

Репозиторий содержит документированную информацию системы менеджмента 
информационной безопасности (СМИБ), ведущуюся в соответствии с 
требованиями п. 7.5 ISO/IEC 27001:2022.

## Структура
- policies/ — политики
- procedures/ — процедуры
- registers/ — реестры
  
## Порядок работы с репозиторием
- Документы ведутся в формате Markdown.
- Изменения вносятся через отдельные ветки и Pull Request.
- Утверждённые редакции помечаются тегами версий.
